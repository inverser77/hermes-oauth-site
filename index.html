Hermes Agent (personal)

이 페이지는 개인용 자동화 에이전트 Hermes Agent의 OAuth 앱 홈페이지입니다. 이 앱은 소유자 한 사람이 자기 Google 계정의 데이터를 다루기 위해 쓰는 비공개 도구이며, 일반 사용자에게 제공되지 않습니다.

This is the home page of a personal, single-user OAuth application used by its owner to operate a self-hosted automation agent (Hermes Agent). It is not offered to the public.
