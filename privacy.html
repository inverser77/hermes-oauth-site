개인정보처리방침

최종 갱신: 2026-11-11

1. 이 앱은 무엇인가

Hermes Agent (personal)는 소유자 한 사람이 자신의 Mac에서 운영하는 개인용 자동화 에이전트입니다. 소유자 본인의 Google 계정에서만 쓰이며, 다른 사용자에게 제공되지 않습니다.

2. 어떤 데이터에 접근하는가

소유자의 지시에 따라 소유자 본인의 Gmail, Google Calendar, Google Drive, Sheets, Docs, 연락처(People API) 데이터를 읽거나 씁니다. 접근 범위는 Google 동의 화면에서 소유자가 승인한 범위로 한정됩니다.

3. 데이터를 어떻게 다루는가

  • 데이터는 소유자의 컴퓨터에서만 처리되며, 소유자 외의 어떤 사람이나 회사에도 공유·판매·제공되지 않습니다.
  • OAuth 토큰은 소유자의 컴퓨터에만 저장됩니다.
  • 처리에 필요한 범위를 넘어 데이터를 보관하지 않습니다.

4. 접근 철회

소유자는 언제든지 Google 계정 권한 페이지에서 이 앱의 접근을 철회할 수 있습니다.

5. 문의

이 앱의 소유자에게 문의: Google Cloud 콘솔 OAuth 동의 화면에 등록된 지원 이메일.

Privacy Policy

Hermes Agent (personal) is a personal, single-user automation agent that its owner runs on their own computer. It is used only with the owner's own Google account and is not offered to anyone else.

On the owner's instruction it reads or writes the owner's own Gmail, Google Calendar, Google Drive, Sheets, Docs and Contacts data, limited to the scopes the owner approved on the Google consent screen.

Data is processed only on the owner's computer. It is never shared with, sold to, or disclosed to any third party. OAuth tokens are stored only on the owner's computer, and no data is retained beyond what the requested task needs.

The owner can revoke access at any time at https://myaccount.google.com/permissions.
